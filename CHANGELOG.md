# 0.1.0 — first playable prototype
- Icon-first ApplicationV2 interface.
- Gathering choice (careful/bold), success checks, loot, rare drops, attempt limits.
- Recipe crafting (standard/inspired), consumption and rollback on output failure.
- Materials backpack, owned character selection.
- GM Studio for materials, nodes, recipes and resets.
- World Item output integration, safe fallback loot.
- Scoped CSS and configurable Alt+G shortcut.
- GitHub manifest URL and direct ZIP distribution for Foundry installation.
