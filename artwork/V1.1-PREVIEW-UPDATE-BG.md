# Gathering & Crafting v1.1 — одобрени временни икони

Това е **GitHub staging клонът**, подготвен за обновяването с **224 уникални 256×256 WebP икони** за Foundry V14 / dnd5e 5.3.3.

## Какво вече е в GitHub
- `artwork/preview-224-manifest.json`: 224 официални item ID-та, оригинални `img` пътища от `data/catalog.json`, уникални SHA-256 хешове и произход.
- `tools/apply-preview-224.py`: автоматична проверка на 224 различни WebP файла, коректните пътища, размер 256×256, ZIP и SHA-256, безопасно копиране и резервни копия.
- `tools/tests/test_preview224.py`: тестове за правилен манифест, липса на дублирания и правилни WebP размери.
- `.github/workflows/preview-224.yml`: CI проверка на съответствията; **компилира инсталируем ZIP само когато истинските 224 файла са налични в хранилището**.

## Какво още НЕ е в GitHub

**Бинарните 224 WebP файла не са качени в GitHub**. Техният общ оригинален пакет е наличен в текущия ChatGPT разговор като `gathering-crafting-v11-224-approved-overlay-for-github.zip` (~3.4 MB). GitHub API връзката позволява текстови промени, но не разполага с директен способ да премести този локален ZIP като бинарен файл, затова CI умишлено НЕ произвежда обновяване без него.

За да се завърши:
1. Изтегли `gathering-crafting-v11-224-approved-overlay-for-github.zip` от разговора.
2. В GitHub отвори клона `update/v1.1-preview-224` и използвай **Add file → Upload files**, като го качиш на път `artwork/preview-224-overlay.zip` (преименувай файла преди качване).
3. След качването workflow `Validate v1.1 preview artwork update` ще тества реалните изображения и ще изработи `gathering-crafting-v1.1.0-preview.1.zip` като GitHub Actions артефакт за тестово инсталиране.
4. След успешна проверка във Foundry V14 можем да оформим истинския manifest download и публичен release.

## Инсталация без GitHub upload

Можеш да приложиш същите 224 изображения върху вече инсталиран `gathering-crafting`, като използваш готовия ZIP от разговора, без да сменяш модулния код. За GitHub checkout:

```powershell
py tools/apply-preview-224.py --overlay "D:\Downloads\gathering-crafting-v11-224-approved-overlay-for-github.zip"
py tools/apply-preview-224.py --overlay "D:\Downloads\gathering-crafting-v11-224-approved-overlay-for-github.zip" --apply
```

Този скрипт НЕ променя `module.json`, `data/catalog.json`, `scripts/main.js` или оригиналната v1.0.0. Прилагането върху checkout се прави на staging клон, **не върху main**, докато няма успешни тестове.

## Важно относно качеството

Потребителят одобри **84 икони за временна употреба**. Останалите 140 са подбрани по тематика от борда. Това е завършен **preview комплект за 224 предмета**, **не** са 224 отделно рисувани 1024×1024 оригинала. Затова PR за строгия original-art процес остава отделен и непроменен. **Няма публикувана v1.1.0 в main**, докато 224-те бинарни файла и инсталационният ZIP не са реално проверени.
