# Gathering & Crafting 1.0.0 — original art gate

**The stable module is currently v0.8.2. This is a DRAFT preparation branch, not a 1.0 release.**

The user requires a separate, item-specific, hand-painted fantasy illustration for each of the **204 unique items** (224 catalogue references). No sprite-sheet crops, generic recolors, or repeated images can pass the intended 1.0 QA.

- Separate original art with bundled WebP files and named catalog mapping: **11**
- Unique item designs still to generate and visually review: **193**
- Counts include **102** materials (including 18 monster drops) and **122** recipes; **20** IDs recur as material and recipe results and must use one shared item image.
- Source manifests at `data/artwork-v1-status.json`; automated gate at `tests/artwork-release-gate.cjs`.

**GitHub CI:** the art audit prints incomplete items on 0.x versions but prevents any 1.x package from succeeding while the individually-painted artwork coverage is incomplete. The QA gate checks unique ID to image identity, bundled WebP validity and file hashes. Visual similarity to the user's 5e reference still requires human inspection.
